
# 缺席

**假期调休调班**：本周是国庆节假期的前半部分。正式的法定国庆节假期是`10.1--10.7`。节前（`9.20 周日`）和节后（`10.10 周六`）各补一天班，垃圾死了。

- 本周三（`20260930`） 
  * 今天是国庆假期前最后一个工作日，和媳妇儿去北大国际检查，然后也顺便办了双套餐和额外的无创检查，费用分四笔，总计交了 **`72145.2元`**。
  * 晚上和媳妇儿一起去吃了农大附近的鸡公煲，味道不行，媳妇儿说米饭也有点酸了，后面不会再来了。
- 本周四（`20261001`） 
  * **今天国庆假期第一天**，不过申请了加班，所以垃圾时间直接过。
  * 晚上和媳妇儿在润千秋佳苑下面的山西刀削面吃了个韭菜鸡蛋盖饭；媳妇儿是第一次到这儿吃，点了个酸汤面，她说还凑合吧，稍有点油。
- 本周五（`20261002`） 
  * **今天国庆假期第二天**，同样申请了加班，所以垃圾时间直接过。
  * 晚上和媳妇儿一起去西北旺万象汇吃了个狗子咖喱（`金宗咖喱(西北旺万象汇店)`）。
  * 然后在里面和周边都逛了一下：先是在盒马逛了逛，买了点儿东西（给媳妇儿买了个椰子，直接喝纯正椰汁，不过可惜都是果肉，椰汁没想象那么多）；然后绕着万象汇逛了一圈，逛到了`夏霖园`、`秋露园`之类的之前没去逛过的老旧住宅楼附近，发现有个什么豫娃子的河南风味饭店，回头可以考虑试试。
- 本周六（`20261003`） 
  * **今天国庆假期第三天**，同样申请了加班（不过是最后一天加班），所以垃圾时间直接过。
  * 晚上下班后和媳妇儿去昨天发现的`豫娃子胡辣汤（西北旺店）`吃了饭，`烩面`反而是相对最差的，剩下的`胡辣汤`、`牛肉水煎包`、`菜角`、`糖糕`都不错；价格也相对便宜。所以后面这个店或者这个品牌的分店都是可以再试试的。
  * 晚上媳妇儿提议玩三国杀，好久没玩了。结果很长时间不玩后真的挺好玩的，一下子玩到凌晨两点多。
- 本周日（`20261004`） 
  * **今天是国庆假期第四天**，我不再加班去了。本来媳妇儿想去单位，但是昨天睡得晚，再加上我一直说别去了，最后就没去，俩人白天继续在家玩三国杀，
  * 到了晚上和媳妇儿去世纪金源吃了个`肉肉大米(世纪金源店)`。这家总体来说不如APM那家，但是主要是布局之类的问题，味道和价格都一样的。
    + 不过我这次最大的经验是：***后面还是吃`68元两块汉堡肉饼`的套餐吧***，`78元三块肉饼`那个套餐真的有点撑。。。
  * 吃完在世纪金源里转了转，然后去果蔬好，会员卡续了个费，买了一些水果。果蔬好还是服务好啊，什么菠萝、西瓜等各种可以切好。而且我们切菠萝的时候，有个大叔让新开一个西瓜，切四分之一都可以。
