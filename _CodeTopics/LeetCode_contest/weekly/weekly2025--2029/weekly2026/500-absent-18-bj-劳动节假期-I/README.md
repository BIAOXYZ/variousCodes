
# 缺席

**假期调休调班**：本次五一劳动节假期休 **`5.1--5.5`**，共计 **`5`** 天。然后 **`5.9周六`** 调班。

- 本周五（`20260501`） 
  * 今天是五一假期第一天，快中午起来，打车去`北京柏悦酒店`。到酒店后办checkin，之前备注里写的要北京柏悦的三种不同的房卡，已经提前准备好了，这点算加分。但是因为假期人太多，又不是高峰第一晚（高峰是4.30晚上）入住的，所以`尊享CBD景观客房`里楼层较高的都没了（除非愿意等到四点以后），最后给了38层的房号 `3805` 的房间。
    + 两晚住下来，整体感觉就是一般吧：卫生间我觉得很不错；淋浴我觉得一般，媳妇觉得不错；浴缸她也觉得不错，但是我没用。——但是作为凯悦集团的头部品牌，洗护用品用大瓶实在是太小家子气了。
    + 不过后来发现北京柏悦所在的`北京银泰中心`地下可以直通国贸商城，感觉还是很不错的。要知道国贸也有好几个酒店，回头都住一下试试。
  * 到房间休息了一会儿，就去吃饭了。在银泰三楼的`红渡秩麵 (银泰中心店)`吃了酱油拉面，真的好吃——溏心蛋甚至超过了新加坡的鸡王拉面。后面必须再来。
  * 然后去王府井，在王府井的几个商业中心逛来逛去，三个老铺都看了，现在溢价有点高，不值得了。不过偶然在王府井喜悦的`HERE奇梦岛（王府井喜悦店）`发现了一种特别可爱小毛绒挂件，叫`Pippy-小恶魔系列毛绒盲盒`。先后分三次买了6个（单价 **`39元/个`**）。
  * 晚上去APM的`肉肉大米（王府井apm店）`吃了个晚饭，很久没吃这个，感觉还是很不错。
  * 吃完回去的路上在APM负一层的泡泡玛特买到了两个星星人毛绒挂件，之前所有逛过的店都没货，这里竟然买到了。
- 本周六（`20260502`） 
  * 早上起来去柏悦66层的`北京亮`餐厅吃了个早饭，总体感觉不错——品类虽然没那么多，但是也不算少，品质比较在线。
  * 然后决定去看刚上映的`《寒战1994》`，选来选去，选了一个`搜秀影城`，是在东城的一个老旧商业中心`搜秀城`。当时就是觉得一来票价便宜，二来支持下老的商业中心，三来看介绍说那里是最早的二次元"圣地"，所以想着支持下。结果影院里看电影的倒是不多，但是竟然只有卖饮料没有卖爆米花的，也太敷衍了。
    + 然后看完电影上厕所，服了，***史上最差的影城没有之一***：9楼男厕五个小便池，三个是积满水堵着的，两个洗手池全部没水！下了一两层，去卫生间，两个洗手池就一个能用，另外一个是坏的，一个老大爷钻在下面修，我真是服了。妈的辣鸡商业中心赶紧完蛋。至于所谓的二次元圣地。。。每一层就那么小，店铺排得密密麻麻的，别说跟王府井喜悦比了，简直跟合生汇负一层（还是负二层）那一块都没得比。
    + 回到电影本身的话，75分到80分吧，而且圈钱意味有点太明显了——我第一次见到结尾电影自己提示观众有彩蛋的。。。说白了就是下一部再赚一波电影票钱呗- -
  * 接着和媳妇儿打车去`798艺术区`，这里果然跟视频里说的一样，好多店关门，挺萧条的。结果不幸又碰上降温和下雨，逛来逛去又冷又累，最后吃了点饭打车回酒店了。
  * 晚上也不想走远了，打算就去国贸商城逛逛。结果一出去刮着冷风，又不想去了。但是我突然想到是不是能完全从室内走过去，结果还真有。并且查了查国贸附近的地下通路还是挺发达的，回头再探索探索吧。可惜转了半天也没啥想吃的，最后又回银泰在`红渡秩面`吃了个饭。
- 本周日（`20260503`） 
  * 办入住时候前台就主动给延迟到`16点`退房，这个真的挺好的。所以中午媳妇儿叫了个客房送餐，我继续睡会儿，到了下午四点多才退房。
  * 前台寄存下行李后去国贸逛了逛，然后在`安记食肆 (国贸商城店)`吃了个晚饭，总体一般偏好一点，不一定会再来。——羊肉泡馍我应该让他们再加点盐的，失误了。
  * 最后就是打车回家，到家后媳妇儿把最后一个没拆的`Pippy-小恶魔`拆了，竟然开出了前五个都没开出的黑翅膀娃娃〜算是圆满了。
