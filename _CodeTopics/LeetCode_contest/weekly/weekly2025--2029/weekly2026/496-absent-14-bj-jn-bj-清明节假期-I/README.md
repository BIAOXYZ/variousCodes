- 本周六（`20260404`） 
  * `趵突泉泉群地质公园`：
    + 今天早上起来打车去`趵突泉泉群地质公园`，门票 **`40元`**。趵突泉的水确实是最大的，但是里五层外五层围了好多人。这个地质公园还有很多别的泉，但是跟趵突泉没得比。但是这里所有的泉水都特别清澈。
    + 然后在这个公园里转，发现了一个画家（`李苦禅`）的纪念馆。去里面转了转，**`39元`** 买了一个盖章的纪念册，那个纪念册与众不同之处在于，它盖的是类似画家作品的章子，感觉很有创意并且也很好看，算是意外的发现。
    + 后来还去了`李清照纪念堂`（`万竹园`），外面墙壁上有很多雕刻的李清照的词。可惜，最牛的《声声慢》竟然不是独占一块，而是和一首《丑奴儿》一起的。。。
  * 中午在这个公园北门附近的一家店（`聚泉楼`）吃的饭，感觉踩雷了。山东煎饼还可以，其他的菜就一版，最后一个红烧黄鱼简直难吃死了，甜口的，有病吧。
  * 吃完去恒隆广场转了转，然后发现这里是没有奢牌的。查了下原来济南的奢牌不在恒隆，而在隔壁的`贵和购物中心`。去贵和购物中心看了看，最高的也就是 LV。然后是走到洲际酒店附近打车回酒店，准备下午开会。下午 `17:30` 开会，开了一个小时左右结束。
  * 然后去行政酒廊简单吃了点，感觉还凑合吧，虽然热菜不多，但是算是我爱吃的。不过不能点餐，就是厨房做好，然后自助餐的形式。
  * 晚上打车先去了`黑虎泉`所在的地方，不过先看了`玛瑙泉`，后面才看了`黑虎泉`和其他泉——这里的泉水更清澈，感觉比趵突泉地质公园那些泉水还清，真的是清澈见底。这边有那种可以直接饮用的泉水，扫码一次，出一点。只能说在饮水方面济南人民是真的幸福，过去甚至很多人家里都有泉水。
  * 接着去了`芙蓉街`，然后顺着`芙蓉街`一直逛到`曲水亭街`，直到`大明湖`。
- 本周日（`20260405`） 
  * 今天上午去了酒店的一个撸猫的地方，叫“猫咪乐园”。**`20元`** 一位还送一包冻干，也太便宜了。里面是很多被收养的猫咪，品种猫的话品相都不太好（不然也不会被遗弃了）。有只三花玳瑁和`喉宝`性格挺像的，就是比`喉宝`瘦了一大圈。猫猫们吃冻干还挺快的，于是喂完送的两包，又去买了两包（**`6元`** 一包，**`10元`** 两包），过了一会儿也喂完了。
  * 晚上坐 17:10 的高铁回北京，到了之后在`北京南站`旁边的一家快餐店吃了个番茄盖饭，就中规中矩的水平吧。
  * 然后打车回家，到家后继续干活。
