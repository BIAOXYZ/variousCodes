
# 缺席

- 本周一（`20260518`） 
  * 因为没有挂到`北大一院`周一上午的号，所以只能下午去。
  * 中午在家里做了些西红柿鸡蛋面，吃完我爸妈回酒店休息下，下午一点打车从酒店出发，去`北京大学第一医院`位于西城`西什库大街8号`的那个院区（`厂桥院区`），赶`14:00--14:30`（其实时间要求没那么严格）的号。这次还是挂了 **`500元`** 的特需号，排了一阵以后进去，是一位张姓医生。结论也跟我们想的类似，并且其实更好，比如：
    + 张医生说两年前来看是`400多`的肌酐，她以为两年后要到`800`了，结果这个月才刚过`500`。
    + 此外她还指出，最近这次测的500，有可能是因为血压和贫血导致的——高压比较低以及贫血都会导致肌酐偏高，因此让回去再测一下血常规。
    + 但是她也指出，透析终究是不可避免的。现在可以考虑做个LOU（应该是指`动静脉内瘘`的`瘘`）。然后也讲解了`腹透`和`血透`的优劣势。我问了现在我爸比较适合哪种？她回答先建议腹透，三到五年后情况更严重了再做血透，两种方式不冲突。
  * 检查完后我爸心情好了不少（因为家里那边医院的关医生也是说他的情况算很不错了），然后一起打车回去。晚上在小区里和周边转了转，最后去`小二包子铺`吃了个饭。
- 本周二（`20260519`） 
  * 今天媳妇儿就上班了，我则继续请假。不过因为检查算是很顺利，所以父母昨天就打算今天回了。
  * 中午父母过来家里做了个饭，简单一吃就回去休息了。然后下午先退房来家里坐会儿，`15:45`左右打车出发去北京西站。
  * 把他们送过安检之后，我就在周边转转，等他们确定上车了，就去`穆兰驼`吃了个番茄拌面，吃完坐公交回去了。这次发现 `394路` 不用换乘就可以到——虽然要坐的站数有点多- -。
- 本周五（`20260522`） 
  * 今天和媳妇儿去试了试另一家烤肉自助品牌：`鹤一鹤烤肉自助（万柳店）`。总体评价是比作作烧肉便宜，但是可吃的肉少，味道也稍差一点点——不过吃是没问题的。此外，水果、冰激凌啥的都很多，只是肉不如作作。
- 本周六（`20260523`） 
  * 今天媳妇儿上午去加班，我在家边看电脑边做ppt。
  * 下午三点多媳妇儿下班回来，俩人一起打车去`北京海淀稻香湖希尔顿花园酒店`。checkin完成后去附近的一家回民的店吃了个拉面，味道还不错，但是老板不舍得开空调，太热了。
  * 然后打车去`海淀大悦城`，对这里印象不错。商场很凉快，也有很多休息的地方，活动也搞得不错——比如一层还是负一层有一个大家坐小板凳免费观影的活动，叫`大悦光影剧场`。反正虽然只是第一次来，但是对这个商场印象就挺不错，将来买的房子附近的商业中心有这个水平也知足了。
- 本周日（`20260524`） 
  * 今天正常睡到中午起来退房，然后打车去回龙观的一个不在商业中心里的店（`潮顺记·海鲜粥底火锅(回龙观店)`）陪媳妇儿吃海鲜粥。真的挺不错的，我觉得这是我吃过的最好吃的海鲜粥了——我平时基本不吃这玩意儿的，但是这家的我一碗粥基本吃完了。不过粥吃完后再下进去的鸡肉相对一般，下次不点了。
  * 然后打车去`超级合生汇`逛了下，比之前来好多了，主要是店终于多起来了，人也多了不少。但是总体来讲还是一般，不如`海淀大悦城`。逛了一圈，以及在星巴克休息了会儿。最后买了两个阿甘锅盔打车回家了。
