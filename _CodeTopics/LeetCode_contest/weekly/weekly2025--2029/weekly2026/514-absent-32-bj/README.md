
# 缺席

- 本周五（`20260807`） 
  * 今天媳妇儿单位大礼堂放电影`《年会不能停2》`，于是下午下班过去。结果快下公交的时候下了超级大的雨，虽然有伞都不太行。而且主要是因为地上积水太多，一走肯定鞋全湿透。最后俩人在传达室躲了一阵雨，媳妇儿找她一个有车的同事来开车带了我们一段（带到餐厅门口）。在餐厅吃了个饭买了点儿饮料就去看电影了。
  * 电影总体可以，但还是有些点没有圆上，比如为什么会有“无限流”？然后结局慷慨激昂一番后就完了？——不过也不算差就是了，而且考虑到是白嫖的，那就很香了。
- 本周六（`20260808`） 
  * 今天上午9点多起来，但是`喉宝`一直要玩，就陪她小玩了会儿。然后去中发百旺的`物美超市(中发百旺商城店)`的`快剪`理发。
  * 晚上媳妇儿加班回来，说想出去住，于是临时决定去`金融街丽思卡尔顿`。结果感觉比较一般吧，虽然之前就已经放低了预期，但是还是有些点比较吃惊：没想到淋浴间往外漏水漏得那么厉害！此外，碰到了一个服务很一般的前台——而且三种房卡竟然只能给两种，再给要收费——无语，这也太low了。
  * checkin后先是去酒店直接连通的`金融街购物中心`的松鹤楼（`松鹤楼面馆(金融街购物中心2期店)`）吃了个饭。然后逛了逛这个商业中心——真的如网上所说，非常萧条。
  * 然后是打车去`隆福寺夜市`逛了逛，感觉还不错，不过那个看起来是一家三口人卖锅盔的那个摊摊，做的锅盔一般吧。
  * 后来出来隆福寺夜市区域，在街道上逛了会儿，也挺不错的。还在一个新发现的饺子品牌（`馅老满`）买了二两猪肉白菜的锅贴，不过晚上回酒店吃了下感觉就是正常水平。
- 本周日（`20260809`） 
  * 今天和媳妇儿退房后在酒店寄存了下行李，然后打车去`西单更新场`了。这里面积虽然不大，但是布局挺合理的，店也比较偏小众新潮型；而且很凉快，供人休息的座位也很多；此外，没见过那么大的`HARMAY话梅`门店。总体而言算是个不错的商场。此外，也终于亲自验证了之前的疑惑：这里确实可以直通地铁，并且`1号线`和`4号线`都可以。
  * 然后媳妇儿在这边的一个越南菜（`SUSU•小苏苏 (西单店)`）吃了个饭，然后我俩就去`西单大悦城`逛了会儿。最后是打车设置个途径点到酒店取一下寄存的行李，然后回家了。
