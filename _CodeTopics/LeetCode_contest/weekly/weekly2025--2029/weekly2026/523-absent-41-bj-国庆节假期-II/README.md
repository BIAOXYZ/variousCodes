
# 缺席

**假期调休调班**：本周是国庆节假期的后半部分。正式的法定国庆节假期是`10.1--10.7`。节前（`9.20 周日`）和节后（`10.10 周六`）各补一天班，垃圾死了。

- 本周一（`20261005`） 
  * **今天国庆假期第五天**，白天在家里干会儿活和媳妇儿玩会三国杀。
  * 晚上去了马连洼的`田老师大排档(马连洼北路店)`吃了个饭，味道不错，价格是真的便宜，**`5个菜（土豆丝、西红柿炒鸡蛋、炒花菜、狮子头两个、花干两个）`+ `两个饼` + `一碗米饭（无限续）` = `34元`**。我只能说田老师真的是业界良心！
  * 吃完在周边转了转，主要是去了`柳浪家园`和`菊园`两个小区里看了下。只能说，人家柳浪家园一个回迁，比我们这商品房小区都强。。。破防了呀兄弟们～～；菊园倒是不如我们这个小区，但是人家里面就有超市（能买菜关键）和好几个饭店，生活很方便。
- 本周二（`20261006`） 
  * **今天国庆假期第六天**，白天媳妇儿看到小红书说朱辛庄的`中海寰宇未来`已经交房并（***在一手没卖完的情况下***）出现了破发，于是好奇想去看看，八卦下，顺便也打发下时间。快速在链家上约了个中介下午三点去看，然后玩了会儿三国杀就打车过去`中海寰宇未来营销中心`。
    + 到那之后发现中海寰宇未来的营销中心是和中海另一个更晚一些的盘（`中海未来之境`）共用的。于是先是听中介简单介绍，然后是中海自己的销售介绍（这个略有点烦，非得把中海公司的历史、在北京的定位和楼盘等都啰嗦一遍），最后才是看房。
    + 依次看了`未来之境129平四居样板间`、`未来之境108平三居（or 四居？）样板间`，`寰宇未来145平没卖出去的空房`。总之感觉就是中规中矩没有什么亮点，但是位置原因，肯定不能买，太偏了。。。还有个`0055地块`，说是被`未来科学城`官方拿了，准备盖四代宅（`未来城·星寰时光`），不过也没什么兴趣了。
  * 然后打车去超级合生汇，在那边的比格披萨（`比格比萨自助 (北京超极合生汇店)`）吃了个自助，感觉碳水多的情况下，吃饱得好快。。。最后是在周边逛了逛，然后打车回去了。
- 本周三（`20261007`） 
  * **今天国庆假期第七天**，今天媳妇儿去单位加班了，我就在家干干活，学习会儿 + 上上网。
  * 下午搜了下，打算去`二河开21号艺术区`那边逛逛。结果发现整体比较破败，也就运动类的和那个爸爸糖喂绵羊的还行，其他的挺萧条的，海淀弄这些真的不行，和朝阳比差远了，`798艺术区`都比这个强太多了——虽然798街区我也看不上。。。
  * 不过好在当时就从高德上发现这里和`清河之洲`很近，于是俩人又去清河之洲逛了下。这里比那边强多了，不只是因为有水的原因，整体维护也比那边强。不过想打个车发现定位地点也比较模糊。
  * 晚上在清河万象汇负一层那个美食广场和媳妇儿吃了个饭，这次尝试了那家铁板炒饭的鸡排套餐，味道还可以，不过和常规炒饭不太一样。
- 本周五（`20261009`） 
  * 今天上午和媳妇儿去北大国际检查。那边给预约了11点，我们大概10点40左右到。结果说是预约的医生做了个手术，以及国庆期间的检查都排到了这周的原因，人特别多。所以我们等了很久，到下午14点多才看完。——就算有这种理由，我也觉得挺失望的，以为能不排队，结果并没有，还不如当时去美中宜和建档。
    + 医生说媳妇儿可能小概率有地中海贫血，说不放心可以查查。后来电话咨询了岳父岳母等人之后，决定还是不查了——查出来就算最坏的情况也只有四分之一的概率，既然不会选择不生，所以就算了。
  * 检查完先打车回家，弄了弄媳妇儿那个项目结题的代码。晚上一起去海淀黄庄附近`福苗小骆驼烧烤（中关村店）`吃了个饭。媳妇儿比较喜欢，因为是比较正宗的陕西菜，我觉得就正常偏好一点点的水平吧。
- 本周六（`20261010`） 
  * 今天是国庆节后调班，垃圾时间直接过。

  * 今天白天在家干干活和媳妇儿玩会三国杀。
  * 晚上去肖家河的杨国福吃了个饭，又喝了蜜雪冰城的`茉莉绿茶`——这个真是爱喝，当前零卡绿茶的小版。
